This project is from Cornell's ENGRD 2020 Class (Statics and Mechanics of Materials) where we are to design a lift mechanism using a linear actuator. Using the specifications of the linear actuator and the forces acting on the bar, we can deduce useful metrics. For example, we can deduce the max height, max force udnergoing, and geometry. Using these quantities we can strategically select our material and cross sectional area so that our design both  meets the weight and height requirements while retaining weight.
